# 04. Art Bible

## 전체 아트 스타일

| 항목 | 기준 |
|---|---|
| 톤 | 밝고 코믹한 모바일 캐주얼 |
| 형태 | 둥근 실루엣, 과장된 표정, 즉시 구분되는 색 |
| 명암 | 2단 셀 셰이딩 + 부드러운 하이라이트 |
| 금지 | 혐오감이 강한 사실적 표현, 과도한 디테일, 어두운 공포 톤 |
| 가독성 | 5인치 화면에서 종류가 즉시 구분되어야 함 |

## 모바일 세로 화면 기준

| 영역 | 비율 | 내용 |
|---|---:|---|
| 상단 0~25% | 아이, 컨디션, 발사구 |
| 중앙 25~75% | 똥 이동, 장애물, 보스 패턴 |
| 하단 75~100% | 플레이어, 조작 UI, 스킬 |

## 캐릭터 디자인

| 캐릭터 | 디자인 기준 |
|---|---|
| 아이 | 둥근 머리, 큰 눈, 표정 변화가 가장 잘 보이게 제작 |
| 플레이어 | 하단에서 작아도 동작이 읽히는 큰 배트/슬링샷 실루엣 |
| 스킨 | 성능보다 외형 차이를 우선, 판정 크기는 동일 |

## 아이 표정 변화

| 표정 | 눈 | 입 | 색상/효과 | 사용 조건 |
|---|---|---|---|---|
| idle | 기본 | 작은 미소 | 기본색 | 대기 |
| happy | 반달눈 | 웃음 | 노란 반짝임 | good |
| strain | 찡그림 | 힘줌 | 붉은 볼 | bad |
| panic | 커진 눈 | 벌림 | 땀방울 | urgent |
| boss | 날카로운 눈 | 굳음 | 보라 그림자 | boss_sync |

## 보스몹 디자인

| 보스 | 실루엣 | 색상 | 패턴 가독성 |
|---|---|---|---|
| 변기 골렘 | 큰 사각 몸체와 변기 뚜껑 방패 | 흰색/청록 | 방패 열림 상태 명확 |
| 하수도 슬라임 | 말랑한 덩어리와 분열 핵 | 초록/라임 | 분열 전 깜빡임 |
| 악취 드래곤 | 길쭉한 몸과 연기 날개 | 보라/노랑 | 독 구름 범위 표시 |

## 똥 종류별 시각화

| ID | 색/형태 | 이펙트 | 주의 |
|---|---|---|---|
| normal | 갈색 기본형 | 작은 바람선 | 가장 단순 |
| fast | 진한 갈색, 길쭉한 잔상 | 속도선 | 빠름이 보여야 함 |
| heavy | 큰 덩어리, 균열 | 낙하 먼지 | 크기 차이 명확 |
| split | 두 개의 점선 균열 | 분열 예고선 | 분열 전 0.4초 예고 |
| gold | 금색 광택 | 반짝임 | 보상형으로 즉시 인식 |
| poison | 녹색 기포 | 독 연기 | 위험형 색상 |
| bomb | 검은 띠와 심지 | 점멸 | 폭발 범위 표시 |

## 배경 스타일

| 스테이지 | 배경 |
|---|---|
| 방 | 밝은 타일, 장난감 소품 |
| 욕실 | 타일, 욕조, 비누 거품 |
| 놀이터 | 하늘, 미끄럼틀, 모래 |
| 하수도 | 파이프, 녹색 액체, 어두운 가장자리 |
| 보스룸 | 보스 테마 오브젝트와 경고 조명 |

## UI 스타일

| UI | 기준 |
|---|---|
| 버튼 | 둥근 사각형, 눌림 상태 2프레임 이상 |
| 폰트 | 두꺼운 고딕 계열, 숫자 가독성 우선 |
| HUD | 상단/좌우 가장자리, 플레이 영역 가림 최소화 |
| 색 | 주요 행동 버튼은 노랑/초록, 위험은 빨강 |
| 아이콘 | 텍스트 없이도 의미 파악 가능 |

## 이펙트 스타일

| 상황 | 이펙트 |
|---|---|
| Perfect | 별, 큰 임팩트 링, 화면 미세 흔들림 |
| Good | 작은 임팩트 링 |
| Miss | 회색 먼지, 짧은 흔들림 |
| Gold Hit | 코인 파티클 |
| Poison Miss | 녹색 화면 가장자리 |
| Boss Hit | 체력바 흔들림과 큰 타격 숫자 |

## 애니메이션 규칙

| 항목 | 기준 |
|---|---|
| 아이 발사 | 예비 동작 0.25초, 발사 0.1초, 복귀 0.2초 |
| 플레이어 타격 | 입력 후 0.1초 이내 타격 프레임 |
| 똥 회전 | 속도에 비례하되 종류 식별 방해 금지 |
| UI 버튼 | press scale 0.94, release 1.0 |
| 보스 패턴 | 위험 범위 0.6초 이상 예고 |

## 이미지 에셋 제작 규격

| 종류 | 권장 크기 | 포맷 | 배경 |
|---|---:|---|---|
| 아이 표정 | 512x512 | PNG | 투명 |
| 플레이어 | 768x768 | PNG | 투명 |
| 똥 | 256x256 | PNG | 투명 |
| 보스 | 1024x1024 | PNG | 투명 |
| 배경 | 1080x1920 | PNG/JPG | 불투명 |
| UI 아이콘 | 256x256 | PNG | 투명 |

## PNG 투명 배경 규칙

| 규칙 | 내용 |
|---|---|
| 알파 | 배경은 alpha 0 |
| 외곽 | 흰색 fringe 금지 |
| 여백 | 오브젝트 주변 8~16px |
| pivot | 중앙 또는 하단 중앙을 문서화 |

## 파일명 규칙

```text
child_face_{state}_{index}.png
player_skin_{skin_id}.png
poop_{type}_{index}.png
boss_{boss_id}_{state}.png
bg_stage_{stage_theme}_{index}.png
ui_icon_{name}.png
fx_{effect_name}_{index}.png
```

JSON 에셋 key 예시:

```json
{
  "assetId": "poop_gold_01",
  "path": "assets/art/poop/poop_gold_01.png",
  "pivot": "center",
  "hitboxId": "poop_gold_circle"
}
```
