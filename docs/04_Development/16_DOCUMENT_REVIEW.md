| 영역 | 점수 | 평가 |
|---|---:|---|
| 코어 루프 | 8/10 | 상단 발사, 하단 타격, 점수/콤보 구조가 명확하다. |

## 출시 가능성 평가

| 단계 | 가능성 | 조건 |
|---|---|---|
| MVP 출시 | 높음 | 1~5 스테이지, 7종 똥, 1보스, 저장 구현 |
| Soft Launch | 중간 | 잔존/광고/밸런스 지표 수집 필요 |
| 글로벌 v1.0 | 중간 | 콘텐츠 20스테이지, 도감, 라이브 운영 도구 필요 |
| 3년 운영 | 조건부 높음 | JSON 콘텐츠 파이프라인과 시즌 템플릿 자동화 필요 |

## 부족한 점

| 부족 영역 | 문제 | 영향 |
|---|---|---|
| 서버 설계 | Rank/Battle에 필요한 서버 API 미정 | 경쟁 모드 구현 리스크 |
| 분석 이벤트 | Retention, ARPDAU, Funnel 이벤트 미정 | 운영 개선 어려움 |
| 난이도 곡선 | Stage 1~20 외 장기 곡선 부족 | 장기 잔존 약화 |
| 콘텐츠 제작량 | 100종 똥/스킨/보스 제작 비용 큼 | 일정 리스크 |
| 접근성 | 색각/흔들림/진동 옵션 상세 부족 | 사용자 범위 제한 |

| 우선순위 | 제안 | 이유 |

| P0 | JSON schema validator를 가장 먼저 구현 | 모든 확장 시스템의 안정성 기반 |
