# 06. Development Roadmap

## 단계별 목표

| 단계 | 목표 | 완료 기준 |
|---|---|---|
| MVP | 핵심 타격 루프 구현 | 1개 스테이지 플레이 가능 |
| Prototype | 컨디션/똥 종류/점수 확장 | 5개 스테이지와 1개 보스 |
| Alpha | 성장/상점/저장/튜토리얼 | 전체 루프 저장 가능 |
| Beta | 밸런스, QA, 광고/IAP 더미 | 출시 후보 기능 완료 |
| v1.0 Release | 스토어 출시 | 크래시/성능 기준 통과 |
| v1.1 Update | 라이브 운영 시작 | 신규 스킨/미션/보스 |
| v2.0 Update | 시즌/랭킹 확장 | 장기 운영 구조 |

## MVP

| 우선순위 | 기능 | 설명 |
|---|---|---|
| P0 | 기본 인게임 화면 | 아이, 플레이어, 똥, 점수 HUD |
| P0 | 드래그/릴리즈 조작 | 슬링샷 발사 |
| P0 | 충돌 판정 | Perfect/Good/Miss |
| P0 | JSON 로드 | poop/stage 기본 데이터 |
| P1 | 기본 사운드 | 발사, 명중, 실패 |
| P1 | 결과 화면 | 점수와 재시작 |

## 예상 작업 순서

1. 프로젝트 골격과 데이터 로더.
2. 인게임 씬과 입력.
3. 똥 스폰/이동/충돌.
4. 점수/콤보/결과.
5. 컨디션/표정.
6. 특수 똥.
7. 스테이지/장애물.
8. 보스.
9. 저장/성장/상점.
10. 광고/IAP/라이브.

## QA 항목

| 영역 | 체크 |
|---|---|
| 플레이 | 5분 연속 플레이 중 멈춤 없음 |
| 판정 | 경계값에서 예상 judgement |
| UI | 작은 화면에서 버튼 겹침 없음 |
| 데이터 | 모든 JSON schema 통과 |
| 저장 | 앱 종료 후 진행 유지 |
| 광고 | 광고 실패 시 보상 중복 지급 없음 |
| 결제 | 구매 복원 동작 |
