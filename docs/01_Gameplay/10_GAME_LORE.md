# 10. Game Lore

참조 문서: `00_GAME_CONSTITUTION.md`, `01_GDD.md`, `11_STAGE_DESIGN.md`, `12_CHARACTER_BOOK.md`

## 세계관 핵심

이 게임의 세계는 "아이의 컨디션이 세상을 바꾸는 코믹 액션 월드"다. 아이가 먹은 음식은 소화 상태를 바꾸고, 소화 상태는 표정과 똥의 성질을 바꾸며, 플레이어는 날아오는 똥을 홈런처럼 받아쳐 세상의 문제를 해결한다.

| 원칙 | 설명 |
|---|---|
| 코믹하지만 불쾌하지 않음 | 똥은 혐오물이 아니라 장난감 같은 탄환으로 표현한다. |
| 음식이 사건의 원인 | 모든 신규 스테이지/보스/똥은 음식 또는 소화 상태와 연결된다. |
| 성장의 정서 | 플레이어와 아이가 함께 성장하며 더 어려운 상황을 즐겁게 극복한다. |
| 시즌 확장성 | 축제, 우주, 학교, 하수도 등 어떤 테마도 음식/소화 사건으로 연결 가능해야 한다. |

## 기본 서사

```text
아이가 새로운 음식을 먹는다
-> 소화 상태가 특이하게 변한다
-> 이상한 똥 에너지가 발생한다
-> 마을/스테이지에 사건이 생긴다
-> 플레이어가 타격 액션으로 사건을 해결한다
-> 도감, 음식, 스킨, 보스 기록이 해금된다
```

## 주요 세력

| 세력 | 역할 | 콘텐츠 연결 |
|---|---|---|
| 아이와 플레이어 | 주인공 듀오 | 성장, 표정, 스킨, 발사 모션 |
| 음식 연구소 | 음식 해금과 튜토리얼 제공 | Food System, Mission |
| 냄새 군단 | 보스와 장애물의 원인 | Boss, Stage |
| 도감 협회 | 수집 보상 제공 | Collection |
| 시즌 위원회 | 주간/시즌 이벤트 운영 | Rank, Season |

| 챕터 | 스테이지 테마 | 주요 음식 | 해금 |

| Chapter 1 | 공원 | 바나나, 우유 | 기본 컨디션, normal/fast |
| Chapter 2 | 도시 | 햄버거, 콜라 | 반사 장애물, heavy |
| Chapter 3 | 학교 | 피자, 요구르트 | NPC 보호 미션, split |
| Chapter 4 | 공사장 | 라면, 커피 | 크레인 장애물, bomb |
| Chapter 5 | 축제 | 매운 음식, 아이스크림 | 폭죽 연출, gold/poison 변형 |
| Chapter 6 | 하수도 | 김치, 고구마 | 독가스, sewer boss |

## 컷씬 규칙

| 컷씬 | 길이 | 스킵 | 목적 |
|---|---:|---|---|
| 첫 음식 섭취 | 3~5초 | 가능 | 음식 효과 설명 |
| 보스 등장 | 4~7초 | 1회 시청 후 가능 | 보스 정체와 패턴 암시 |
| 챕터 클리어 | 5~8초 | 가능 | 다음 지역 동기 부여 |
| 희귀 똥 발견 | 2~3초 | 불가 | 수집 보상 강조 |
