# 01. Game Design Document

## 게임 개요

| 항목 | 내용 |
|---|---|
| 가제 | 똥 홈런 게임 |
| 플랫폼 | 모바일 iOS/Android |
| 화면 | 세로형 9:16 |
| 장르 | 캐주얼 액션, 슬링샷, 리듬형 타격 |
| 한 판 목표 | 날아오는 똥을 정확히 맞춰 점수와 콤보를 쌓고 스테이지를 클리어 |
| 차별점 | 아이 컨디션에 따라 똥 종류, 표정, 패턴이 바뀌는 코믹 액션 |

## 타깃

| 타깃 | 설계 기준 |
|---|---|
| 1차 | 10~30대 캐주얼 게임 유저 |
| 2차 | 짧은 플레이와 수집/성장 보상을 선호하는 유저 |
| 플레이 시간 | 출퇴근, 쉬는 시간 기준 1~5분 |
| 난이도 | 초반은 쉬움, 중반부터 반응속도와 패턴 학습 요구 |

## 핵심 재미

1. 날아오는 물체를 정확한 타이밍에 맞추는 즉각적인 타격감.
2. 컨디션에 따라 예측하기 어려운 똥 패턴을 대응하는 재미.
3. 표정, 사운드, 이펙트가 결합된 코믹 리액션.
4. 성장으로 더 강한 타격, 넓은 판정, 높은 보상을 얻는 장기 목표.
5. 수집형 똥 도감, 스킨, 보스 기록을 채우는 반복 동기.

## 게임 루프

| 단계 | 플레이어 행동 | 시스템 반응 |
|---|---|---|
| 준비 | 스테이지/장비 선택 | 컨디션, 장애물, 보스 여부 로드 |
| 조준 | 드래그로 방향/파워 조절 | 궤적 프리뷰 표시 |
| 발사/타격 | 손을 떼거나 버튼 탭 | 투사체 또는 배트 타격 발생 |
| 판정 | 똥과 충돌 | Perfect/Good/Miss 판정 |
| 보상 | 콤보 유지 | 점수, 코인, 이펙트 증가 |
| 종료 | 클리어/실패 | 별 등급, 보상, 다음 목표 표시 |

## 조작 방식

| 조작 | 입력 | 사용 상황 | 구현 기준 |
|---|---|---|---|
| 슬링샷 | 하단 캐릭터를 드래그 후 릴리즈 | 일반 모드 | 드래그 거리로 파워 0~1 계산 |
| 타격 | 타격 버튼 탭 | 보스/러시 모드 | 버튼 입력 후 8프레임 내 판정 |
| 스킬 | 스킬 아이콘 탭 | 게이지 충전 후 | 쿨타임과 게이지 모두 만족 |
| 일시정지 | 상단 버튼 | 모든 플레이 | 게임 시간 scale 0 |

## 판정 시스템

| 판정 | 조건 | 점수 배율 | 피드백 |
|---|---:|---:|---|
| Perfect | 중심 거리 <= hitRadius * 0.35 | 1.5x | 큰 타격 이펙트, 강한 진동 |
| Good | 중심 거리 <= hitRadius * 0.75 | 1.0x | 기본 이펙트 |
| Graze | 중심 거리 <= hitRadius | 0.5x | 작은 이펙트, 콤보 유지 안 됨 |
| Miss | 충돌 없음 | 0 | 라이프 감소 또는 위험도 증가 |

## 점수 시스템

```text
획득 점수 = 똥 기본 점수 * 판정 배율 * 콤보 배율 * 스테이지 배율 * 이벤트 배율
```

| 요소 | 예시 |
|---|---|
| 기본 점수 | normal 100, fast 150, gold 500 |
| 판정 배율 | Perfect 1.5, Good 1.0, Graze 0.5 |
| 콤보 배율 | 10콤보마다 +0.1, 최대 3.0 |
| 스테이지 배율 | Stage 1은 1.0, Stage 10은 1.45 |

## 콤보 시스템

| 조건 | 결과 |
|---|---|
| Perfect/Good | 콤보 +1 |
| Graze | 콤보 유지, 증가 없음 |
| Miss | 콤보 0 |
| 보스 방어 패턴 명중 | 콤보 +2 |
| 스킬 사용 | 콤보 유지, 자동 증가 없음 |

## 캐릭터 시스템

| 캐릭터 | 역할 | 성장 능력 |
|---|---|---|
| 기본 플레이어 | 타격/슬링샷 주체 | 파워, 판정 범위, 코인 보너스 |
| 아이 | 발사 주체 | 컨디션, 표정, 패턴 표시 |
| 보스몹 | 특수 공격과 체력 보유 | 스테이지별 고유 패턴 |

## 아이 표정 시스템

| 표정 ID | 조건 | 게임 영향 | 연출 |
|---|---|---|---|
| face_idle | 기본 | 없음 | 눈 깜빡임 |
| face_happy | 컨디션 좋음 | 골드 똥 확률 증가 | 웃음 |
| face_strain | 컨디션 나쁨 | heavy, poison 확률 증가 | 힘주는 표정 |
| face_panic | 콤보 20 이상 | fast 확률 증가 | 당황 |
| face_boss | 보스 진입 | 보스 패턴 예고 | 긴장 |

## 컨디션 시스템

컨디션은 스테이지 시작 시 기본값으로 결정되고, 플레이 중 이벤트로 변할 수 있다.

| 컨디션 | 설명 | 패턴 영향 |
|---|---|---|
| good | 기분 좋음 | 보상형 똥 증가, 속도 안정 |
| normal | 기본 | 표준 확률 |
| bad | 배탈 | 위험형 똥 증가 |
| urgent | 급함 | 발사 간격 감소, fast 증가 |
| boss_sync | 보스 영향 | 보스 패턴과 동기화 |

```json
{
  "conditionId": "urgent",
  "durationSec": 20,
  "fireIntervalMultiplier": 0.75,
  "face": "face_panic",
  "poopRateTable": "condition_urgent"
}
```

## 똥 종류 시스템

| ID | 이름 | 기능 | 대응 |
|---|---|---|---|
| normal | 일반 똥 | 기본 점수 | 기본 타격 |
| fast | 빠른 똥 | 속도 빠름, 고득점 | 빠른 조준 |
| heavy | 무거운 똥 | 크고 느리지만 튕김 | 강한 파워 |
| split | 분열 똥 | 중간에서 2개로 분리 | 우선순위 판단 |
| gold | 황금 똥 | 높은 보상 | 반드시 명중 |
| poison | 독성 똥 | 놓치면 디버프 | 즉시 제거 |
| bomb | 폭탄 똥 | 명중 시 주변 제거 | 타이밍 활용 |

## 보스 시스템

| 보스 | 해금 | 주요 패턴 | 보상 |
|---|---:|---|---|
| 변기 골렘 | Stage 5 | 방패, 느린 대형 투사체 | 보스 코인 50 |

| 악취 드래곤 | Stage 20 | 3연속 빠른 발사, 독 구름 | 희귀 스킨 |

## 스테이지 시스템

| 구간 | 특징 | 장애물 |
|---|---|---|
| 1~4 | 기본 학습 | 없음 |
| 5 | 첫 보스 | 변기 방패 |
| 6~9 | 속도 증가 | 이동 벽 |
| 10 | 분열 보스 | 점액 장판 |
| 11~19 | 혼합 패턴 | 회전 선풍기, 반사판 |
| 20 | 대형 보스 | 독 구름, 화면 흔들림 |
